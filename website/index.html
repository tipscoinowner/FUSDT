FlashtetherUSDT (FUSDT)

TRON‑based reserve‑backed stable token for DeFi, payments, and liquidity pools.

TRON Stable Token Mint/Burn DEX Liquidity

Overview

FlashTetherUSDT (FUSDT) is a TRC20‑compatible stable token deployed on the TRON blockchain. It is designed to mirror USDT‑like behavior with 6‑decimal precision, owner‑controlled mint/burn, blacklist & pause security layers, anti‑bot launch protection, and seamless DEX liquidity integration.

Architecture

FUSDT is built around a modular architecture:

  • FUSDT Token Contract: Core TRC20‑compatible stable token.
  • FUSDTBuy Swap Contract: TRX → FUSDT on‑chain swap.
  • Peg Bot (off‑chain): Monitors DEX price and triggers rebalance events.
  • DEX Liquidity: SunSwap / JustMoney / other TRON DEXs.

Security & Controls

  • Owner‑controlled mint and burn.
  • Blacklist support for malicious or compromised addresses.
  • Pause mechanism for emergency situations.
  • Anti‑bot launch protection and optional maxTx / maxWallet limits.
  • CI/CD‑ready architecture with static analysis and test support.
